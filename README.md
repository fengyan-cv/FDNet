# \[TMM 2026\]Frequency Decoupled Cross-modal Network with Query Refinement for RGB-D Salient Object Detection
This is the official code repository for "Frequency Decoupled Cross-modal Network with Query Refinement for RGB-D Salient Object Detection." The paper can be found at [Link](https://ieeexplore.ieee.org/abstract/document/11718612)


# Predictions
Experiments are conducted across four tasks: RGB-D SOD (NJUD, NLPR, STERE, DUT, SIP, ReDWeb-S), RGB-D surface defect detection (NEU-RSDDS-AUG), RGB-T SOD (VT821, VT1000, VT5000), and RGB-D COD (CAMO, COD10K, NC4K) . The corresponding predicted saliency maps are available on Baidu Disk (code:753s) [Link](https://pan.baidu.com/s/1FNcO1T-vpb27u6bcDfMGBw?pwd=753s)
