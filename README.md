# \[TMM 2026\]Frequency Decoupled Cross-modal Network with Query Refinement for RGB-D Salient Object Detection
This is the official code repository for "Frequency Decoupled Cross-modal Network with Query Refinement for RGB-D Salient Object Detection." The paper can be found at [Link](https://ieeexplore.ieee.org/abstract/document/11718612)


# Predictions
We evaluate our method across four tasks: RGB-D salient object detection (SOD) on NJUD, NLPR, STERE, DUT, SIP, and ReDWeb-S; RGB-D surface defect detection on NEU-RSDDS-AUG; RGB-T SOD on VT821, VT1000, and VT5000; and RGB-D camouflaged object detection (COD) on CAMO, COD10K, and NC4K.  The corresponding predicted saliency maps are available on Baidu Disk (code:753s) [Link](https://pan.baidu.com/s/1FNcO1T-vpb27u6bcDfMGBw?pwd=753s)
